**The gym does not reliably reward the paper's scientific contribution.** A genuine improvement scores higher, but removing every higher-order edge ties the reference exactly. The substitute benchmark therefore does not demonstrate the paper's central higher-order benefit. An exhaustive solver also ties within seconds. A method that omits 13 of 19 joints scores strictly higher without improving any coordinate. A two-camera ablation loses headline AP and recovery coverage yet outranks the reference in plausible ranking cohorts.

The following departures matter when interpreting this gym:

| Component | Paper | Reproduced gym |

| Cameras | HD nodes 3, 6, 12, 13, 23 | HD nodes 6, 8, 10, 11, 16. |
| Pose/data conventions | Real benchmark annotations and detector observations | All 19 COCO joints; low-confidence source joints are filled with the valid-joint mean, and generated detections carry true person IDs. |

There is a useful noisy triangulation/association signal here, but the **specific higher-order effect is absent at the frozen operating point**: all 282 emitted reference poses across the 72 frames use exactly two views, and deleting every edge larger than two changes no test metric. The same-input shortcut takes about 4.50 seconds including train/test evaluation, versus roughly 15 seconds for the full reference producer. The train-selected improvement does use larger edges, but this alone does not establish a higher-order advantage over a comparably tuned pair-only method. The current reference-versus-baseline gap cannot establish that a better gym result is a better method on the paper's real problem.

Five shortcuts improve at least one scored metric and worsen none: jittered answers, rebuilt answers, identity grouping, truth replacement, and partial poses. Their gains survive any positive finite scale per metric. Four additional examples pay by tying; two of those are explicit reference replays. Exact-copy penalties work on literal copies in this cohort, but use a tolerance of only 1e−9 **mm**, so an immaterial 0.01 mm offset removes the entire penalty.

The brute-force test is too small to establish the paper's computational benefit. The unpruned exhaustive example takes **13.397 seconds** including geometry for all 72 frames (14.50 seconds for the complete scenario), with at most **323 candidates, 11 detections, and 621 memo states** in a frame. Exhaustive search on the reference candidate set takes **14.536 seconds** including geometry (16.27 seconds complete) and ties every metric; its maximum memo states is 594. These are workload observations, not a controlled speed benchmark. No runtime/candidate-count constraint is ranked, so an equally accurate, exponentially scaling algorithm loses nothing. Per-frame timings/counts are saved beside both shortcuts.

**Completeness and failure handling.** The hidden script does not enumerate every method on disk when `scores_train.json` exists. It trusts method names and prediction paths in that editable file; `shortcut_unregistered` demonstrates an on-disk empty method omitted from `results` while a replay receives a reference score. With no registration file it falls back to prediction-file enumeration.

The required worst-value behavior is absent. Empty/all-nonfinite outputs produce null MPJPE, which the rank skips; nonfinite poses can still receive perfect pose-count error. Crashed or missing-artifact runs write no result at all, rather than worst values for all eight scored metrics in the one experiment. Missing-value arithmetic alone would sum to zero, but whether an external service accepts a failed job is unknown; those two crashes are **not** counted as working ties. Plain empty, constant, and all-invalid methods remain below reference in the measured cohort. The demonstrated incomplete-body and moved-truth methods show that task failure can nevertheless outrank reference.

There is no trained fixed detector/reference model in this gym to retrain. The fixed answer dataset is the relevant editable artifact, and its replacement was tested. Moving a baseline alone does not change the independently evaluated own result. Hidden thresholds and evaluator code were never edited. Fake success, timing, and metric fields do not bypass recomputation.

**Execution and restoration.** There are 27 distinct scenarios. The first launcher job exited 127 before experiments; the subsequent three CPU jobs succeeded. All cases invoke train and then the unchanged no-argument hidden shell entry point, saving actual scores or the recorded nonzero test failure. Producers use only public data, generators, baseline code, public train metrics, and, for reference-dependent improve-mode cases, the method code. They do not read the paper, hidden evaluator implementation, or hidden reference scores to construct predictions. Audit-only rank analysis reads the scoring configuration. Reference outputs were recomputed and reused for output-only checks; they can be regenerated from the improve-mode method.

Test invocations run as separate subprocesses in the compute container after artifact creation. They rely only on persisted ordinary files, with no surviving producer, evaluator patches, interpreter changes, or environment tampering; a fresh test job can read the same artifacts. `redteam/execute.py` snapshots and restores dataset, checkpoint predictions, and score artifacts after each scenario, including failures. [restoration.json](redteam/restoration.json) verifies their original SHA256 hashes, absence of extra checkpoint predictions, and unchanged method/baseline/eval/data/environment/scoring sources relative to start commit `8b9a054`.

Run all cases inside the gym container with `bash redteam/run_all.sh`; each individual `run.sh` is also executable with bash. Predictions and routine logs are ignored and reproducible. Small scores, execution/error records, train-selection tables, timing/count tables, and copied job logs are retained under `redteam/`. The temporary `scripts/run.sh` is restored with git. Pre-existing README/manifest device placeholders and trajectory deletions are recorded in `redteam/initial_status.txt` and left as found; scheduler control `action.yaml` is set to done as required. No gym repair is included in this audit.

For the next iteration, keep immutable hidden answers separate from public inputs and generators, remove true detection identities, and use independent real scenes with a demonstrated higher-order ablation gap. Require the complete finite joint schema and define explicit failure values for every scored metric/experiment. Discover submitted methods independently of editable train scores. Enforce essential recovery/completeness constraints before compensating metrics, and evaluate runtime/scaling on a workload that cannot be exhaustively solved in seconds if efficiency remains part of the scientific claim.
